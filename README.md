# Гори та Степ · шрифтова майстерня

Монорепозиторій для розробки шрифтів конскрипту **«Гори та Степ»** — фонетичної
абугіди для української мови — та потенційно інших гарнітур.

Знак не малює літеру, а кодує звук: пряме стебло з засічкою — проривні,
хвилясте — протяжні, дуга праворуч — губні, ліворуч — зубні, замкнена дуга —
дзвінкі, петля крізь стебло — задньоязикові, вільний розчерк — плавні.

## Швидкий старт

```bash
pip install -r requirements.txt
make            # build + test + preview
```

Готові шрифти з'являються у `fonts/`, зразки — у `docs/preview-*.png`.

| Ціль | Що робить |
|---|---|
| `make build` | збирає всі гарнітури з `sources/` у `fonts/*.ttf` |
| `make test` | smoke-тести: покриття абетки, лігатури, метрики, контури |
| `make preview` | рендерить зразки текстів у `docs/` |
| `make clean` | прибирає артефакти |

## Як це працює

```
sources/<гарнітура>/glyphs.json   контури штрихами (SVG-шляхи M L H V Q)
sources/<гарнітура>/family.json   метадані: назви, метрики, стилі
        │
        ▼  tools/build.py + tools/stroker.py
штрих → семплінг Безьє → офсетний полігон (round/butt капи) → TTGlyphPen
        │
        ▼  fontTools.fontBuilder + feaLib (лігатури дж/дз)
fonts/HoryTaStep-<Стиль>.ttf
```

Гліфи описуються *штрихами* — так само, як на інтерактивній сторінці
скрипту, — а не готовими контурами. Товщина, капи і геометрія стилю
(друкований/рукописний) задаються в `family.json`, тож одна зміна контуру
в `glyphs.json` оновлює всі накреслення.

## Стилі

- **Drukovanyi** — друковане накреслення: прямі стебла з засічками,
  правильні дуги, обрубані капи.
- **Rukopysnyi** — рукописне: розчерки-ніжки, каліграфічні дуги,
  заокруглені капи.

Великі й малі літери мапляться на ті самі гліфи (унікейс).
`д+ж` і `д+з` замінюються лігатурами через OpenType `liga`.

## Додати нову гарнітуру

1. Створіть `sources/<назва>/` з `family.json` та `glyphs.json`
   (за зразком `sources/hory-ta-step/`).
2. `make` — збирання, тести і зразки підхоплять її автоматично.
3. CI на GitHub зробить те саме на кожен push, а на тег `v*` —
   прикріпить .ttf до релізу.

## Реліз

```bash
git tag v0.2 && git push --tags
```

GitHub Actions збере шрифти, прожене тести і опублікує реліз із .ttf.
